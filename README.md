# 关掉广告

一个离线网页小游戏。做饭、下课表、买门票……六件普通的小事，总有广告和弹窗来打岔。看清每次点击的去向，完成自己原本想做的事。

## 开始游玩

1. 下载仓库中的 [关掉广告.html](./关掉广告.html)，或通过 **Code → Download ZIP** 下载仓库后解压。
2. 用支持 JavaScript 的现代浏览器打开 `关掉广告.html`。
3. 在选关页任选一关开始。

游戏的样式、脚本和插画都在这一个 HTML 文件里。下载后可离线游玩，无需安装、注册或启动服务器。若文件预览不能运行游戏，请改用浏览器打开。

## 六件小事

1. **一顿晚饭**：回到原始菜谱，找到烤箱温度。
2. **一份课表**：核对发布者、学期与文件格式，拿到正确的 PDF。
3. **一张门票**：在 ¥50 预算内只买门票，移除附加项和自动续费。
4. **一节小课**：找到真正的薄荷修剪课，记住课程要点。
5. **一条好消息**：撤回无关来源的通知权限，找回取书消息。
6. **一次告别**：完成取消订阅，核对最终状态与下次扣费。

六关全部开放，可以任意顺序游玩。完成全部六关后可查看最终小结。

## 怎么玩

- **记住目标**：游戏内浏览器的书签栏显示本关目标，点击可查看完整说明。
- **先检查，再决定**：点「检查」，再点可检查的控件，查看来源、去向和点击后果；这次检查不会执行该控件的动作。
- **走错了可以回来**：使用游戏内浏览器的返回、返回原页面或关闭标签页等控件，脱离广告页面。
- **随时停一下**：浏览器菜单里有暂停、重试本关、减少动态和返回选关。
- **键盘操作**：Tab 切换控件，Enter 或空格操作，Esc 关闭说明或暂停。没有倒计时，也没有速度惩罚。

返回选关会保留当前尝试，可点「继续上一件小事」接着玩。重新点击关卡卡片会开始该关的新尝试；重试本关保留其他关卡的完成记录。

**进度只保留在当前页面中。刷新或关闭真正的浏览器页面会丢失进度，游戏没有自动存档。** 选关页的「重置进度」也会在确认后清空本次记录。

## 画面与动效

提供电脑和窄屏布局，以及手动「减少动态」选项，并响应系统的减少动态偏好。第三关起，每关包含横幅、插画和浮动推广；部分假关闭入口会再弹出一张广告卡，浮层最多同时两张。广告有各自的关闭路径，游戏内浏览器导航保留在广告之外。

## 离线与安全

游戏中的品牌、网址、消息、账户和订单均为虚构。下载、付款、通知权限与页面跳转都只改变游戏状态，不会触发真实下载、支付或权限请求，也不会操作真实账户。

所有素材内嵌，不加载外部资源；游戏不发送网络请求，不收集个人信息，也不使用追踪或持久化存储。

## 开发与验证状态

本仓库当前提供构建后的单文件版本；拆分源码、构建脚本和测试文件暂未随仓库发布。

对应版本已通过 70 项 Node 自动化检查，以及后四关共 96 种广告关闭顺序检查，重新构建的 HTML 与仓库中的文件一致。真实浏览器交互、视觉布局、手机触摸及屏幕阅读器体验仍待验证；现有自动化检查不代表这些体验已经验收。
