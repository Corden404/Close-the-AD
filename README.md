# 关掉广告

一个离线网页小游戏。做饭、下课表、买门票……九件普通的小事，总有广告和弹窗来打岔。看清每次点击的去向，完成自己原本想做的事。

## 开始游玩

1. 下载仓库中的 [关掉广告.html](./关掉广告.html)，或通过 **Code → Download ZIP** 下载仓库后解压。
2. 用支持 JavaScript 的现代浏览器打开 `关掉广告.html`。
3. 在选关页任选一关开始。

样式、脚本和原创 SVG 插画都在这一个 HTML 文件里。下载后可离线游玩，无需安装、注册或启动服务器。若文件预览不能运行游戏，请改用浏览器打开。

## 九件小事

1. **一顿晚饭**：回到原始菜谱，找到烤箱温度。
2. **一份课表**：核对发布者、学期与文件格式，拿到正确的 PDF。
3. **一张门票**：在 ¥50 预算内只买门票，移除附加项和自动续费。
4. **一节小课**：找到真正的薄荷修剪课，记住课程要点。
5. **一条好消息**：撤回无关来源的通知权限，找回取书消息。
6. **一次告别**：完成取消订阅，核对最终状态与下次扣费。
7. **一次预约**：辨认官方售后，预约周六上午的免费到店检测，不购买优先服务。
8. **一份工作**：比较直招、固定底薪和双休条件，零费用投递已有简历，不开放通讯录。
9. **一段出行**：从不同日期、时段、换乘与退改方案中，选出预算内的周六上午直达可退车票。

九关全部开放，可以任意顺序游玩。后三关有更密集的广告、多步诱导和多项约束；难度来自核对信息，没有随机死路或倒计时。每关都可以返回、修改选择，并核对最终回执。完成全部九关后可查看最终小结。

## 怎么玩

- **记住目标**：游戏内浏览器的书签栏显示本关目标，点击可查看完整说明。
- **先检查，再决定**：点「检查」，再点可检查的控件，查看来源、去向和点击后果；检查不会执行该控件的动作。
- **走错了可以回来**：使用游戏内浏览器的返回、返回原页面或关闭标签页等控件，脱离广告页面。
- **随时停一下**：浏览器菜单里有暂停、重试本关、减少动态和返回选关。
- **键盘操作**：Tab 切换控件，Enter 或空格操作，Esc 关闭说明或暂停。新关进入详情、核对和回执时有对应的内容焦点。

返回选关会保留当前尝试，可点「继续上一件小事」接着玩。重新点击关卡卡片会开始该关的新尝试；重试本关保留其他关卡的完成记录。后三关的错误提示会显示在当前表单或核对区域，修改选项后可以再次提交。

**进度只保留在当前页面中。刷新或关闭真正的浏览器页面会丢失进度，游戏没有自动存档。** 选关页的「重置进度」也会在确认后清空本次记录。

## 画面与动效

提供电脑和窄屏样式，以及手动「减少动态」选项，并响应系统的减少动态偏好。打开对话框或暂停时，广告动画停止。

第三至六关各有三个初始推广位；后三关各有六个初始推广位，包含横幅、侧栏、图文卡片、插画广告和浮动推广。部分假关闭入口会再弹出一张广告卡，浮层最多同时两张。每个广告位都能独立关闭；浏览器级返回也能清除浮层。游戏内导航不属于广告层。

## 离线与安全

游戏中的品牌、网址、消息、账户、简历、岗位和订单均为虚构。下载、付款、通知权限、通讯录授权与页面跳转都只改变游戏状态，不会触发真实下载、支付或权限请求，也不会操作真实账户。

所有素材内嵌，不加载外部资源；游戏不发送网络请求，不收集个人信息，也不使用追踪或持久化存储。

## 源码与构建

需要 Node.js 22 或更新版本。基础测试和构建只使用 Node 内置模块，无需安装依赖。

```sh
npm test
npm run build
```

构建生成 `dist/index.html` 和 `dist/关掉广告.html`。仓库根目录的 `关掉广告.html` 是可直接分发的相同单文件版本。

- `build-sources.mjs`：普通游戏与评测共同使用的模块顺序
- `src/content.mjs`：Node 与浏览器共享的完整九关任务说明
- `src/engine.mjs`：关卡状态与通用浏览器操作
- `src/advanced.mjs`：后三关的固定数据、约束、费用与回执
- `src/scenes.mjs`、`src/advanced-scenes.mjs`：页面内容与流程
- `src/ads.mjs`：原创插画、推广内容与广告关闭入口
- `src/app.js`、`src/styles.css`：交互、焦点与布局
- `tests/`：状态机、渲染与事件路由、安全及浏览器测试

### 验证范围

安装开发依赖后，npm run verify:node 会运行全部游戏与评测 Node 测试、构建，并检查根目录 HTML 与两份 dist HTML 逐字节一致。它不会启动浏览器，不能替代浏览器验收。npm run verify 在此基础上再运行游戏与评测两套真实浏览器测试；这需要可用的 Chromium。

本次九关与评测集成通过 93 项游戏 Node 自动化检查，包括原六关回归、新三关成功与误点恢复、条件和附加项组合、九关乱序完成、焦点目标、检查模式与离线限制。原九关版本另对 67 个渲染页面片段进行了 HTML DOM 结构检查：ID 与焦点标识无重复、无嵌套交互控件、描述引用有效、无外部资源。这是结构检查，不是浏览器视觉测试。

广告关闭测试穷举 15,216 种排列：原四个广告关各 24 种，三个新关各 5,040 种。

真实 Chromium 交互测试脚本覆盖 1440、768、390、360、320 像素宽度，成功路径、误点恢复、广告层、触控尺寸、焦点及外部请求检查。可在支持浏览器进程的环境中运行：

```sh
npm install
npx playwright install chromium
npm run build
npm run test:browser
```

测试默认优先使用 `/usr/bin/chromium`（若存在），否则使用 Playwright 安装的 Chromium；可用 `CHROMIUM_EXECUTABLE` 指定其他 Chromium 路径。截图写入本地 `artifacts/`。

**本次集成未执行真实浏览器测试**。Node VM 会实际执行两类构建生成的内联脚本，检查九关启动、任务说明、选关边界与裁判接口隔离；它不验证 Chromium 渲染、视觉布局、手机触摸、浏览器焦点滚动或屏幕阅读器体验。

## 文字接口评测

[`benchmark/`](./benchmark/README.md) 提供与模型服务解耦的文字交互接口，支持九个固定任务、广告 on/off 配对及独立裁判。模型只接收可见 DOM 文字和本轮不透明控件 ID，由宿主用真实鼠标、键盘和滚轮执行。新增三关还会独立核对选择约束及最终回执。裁判仅存在于单独生成的评测页面，不进入普通游戏或模型观察。

```sh
npm run test:benchmark
npm run benchmark -- --stage all --paired --mock random
npm run test:benchmark:browser
```

评测 Node 套件本次通过 109 项检查，覆盖异常结果、批次继续与资源清理；九关 ads on/off 原生浏览器解题脚本已扩展，尚未在本次集成中执行。运行评测需要可用的 Chromium；随机和关键词基线不保证通关，也不代表模型效果。完整轨迹保存在已忽略的本地目录，默认不提交或上传。
